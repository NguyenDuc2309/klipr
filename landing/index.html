Install Klipr in Seconds

Choose your preferred installation method below:

$sudo apt install ./klipr_1.2.3_all.deb

Download the latest release package directly from GitHub Releases.

$git clone https://github.com/NguyenDuc2309/klipr.git && cd klipr && python3 src/main.py

Requires Python 3.10+, GTK4, and PyGObject (`gir1.2-gtk-4.0`).

$nano ~/.config/klipr/settings.json

Configure `historyLimit`, `theme`, `autostart`, and custom `shortcut` keys.
