Everything you need, nothing you don't.

Built to stay out of your way while keeping every snippet within reach.

Clipboard History

Auto-saves text and images. Configurable limit auto-prunes old items to keep things lean.

Instant Search

Real-time search across your entire history. Optimized for IME input with zero lag.

Favorites

Pin important clips to a separate list. Favorites are never auto-deleted.

Image Support

Screenshots and copied graphics saved with inline thumbnails. One-click paste back.

Dark, Light & System

Three themes that follow your desktop appearance or your personal preference.

Lightweight & Native

Pure Python + GTK4. No Electron. Runs silently in the system tray using minimal resources.

Get started in seconds

Ubuntu / Debian — download the .deb and run:

$ sudo apt install ./klipr_1.2.3_all.deb

or

Build from source — see instructions on GitHub
